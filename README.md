# How to Run

## Run C++ Code

Go to the pattern's cpp folder:

```bash
cd PatternName/cpp
```

Compile:

```bash
g++ main.cpp -o main
```

Run:

```bash
./main
```

---

## Run Java Code

Go to the pattern's java folder:

```bash
cd PatternName/java
```

Compile:

```bash
javac $(find . -name "*.java")

and

javac java/com/rupesh/factory/*.java
```

Run:

```bash
java com.rupesh.main.Main
```
